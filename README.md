# ZartApp

Projeto de experiência e interface (UX/UI) de um aplicativo de agendamento de cortes de cabelo para a **Barbearia Zart**.

> Esta etapa entrega o **projeto do aplicativo** (descrição, requisitos, navegação, wireframes e telas). Não há código de aplicação neste repositório.

**Autor:** Jean

## Visão geral

O ZartApp permite que o cliente agende, pague e acompanhe seus cortes pelo celular, enquanto barbeiros e administração organizam agenda, atendimentos e fidelidade em um só lugar.

Identidade visual: **preto** como cor principal e **amarelo** nos detalhes. O logotipo é uma bicicleta estilo Monark em amarelo.
